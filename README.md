## Description

**HelloJavaGUI** is an interactive desktop application that greets the user.  

- Users can enter their name in a text field.  
- A **ComboBox** allows selecting the greeting style (Console or Fancy).  
- The greeting is generated by a specific implementation of the `Greeter` interface, demonstrating **polymorphism**.

This project was built as a practice exercise to learn **interfaces, polymorphism, and Java GUI development**.

---

## Features

- Multiple implementations of the `Greeter` interface:
  - `ConsoleGreeter`: classic greeting with timestamp  
  - `FancyGreeter`: fun, stylized greeting with emojis
- Polymorphic behavior: the same GUI button works with different Greeter implementations without code changes
- Handles null or blank input gracefully
- Simple JavaFX layout with `VBox` and controls (`Label`, `TextField`, `Button`, `ComboBox`)
